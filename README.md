# Élpis - Buscador de Vagas com IA 🚀

Aplicação desenvolvida em Streamlit para pesquisar oportunidades de emprego no Brasil e no exterior, consolidar resultados de múltiplas fontes, exibir mapa interativo e analisar vagas com o auxílio do Gemini (opcional).

---

### 📋 Sobre o Projeto
Este repositório abriga a estrutura da aplicação Élpis para fins de *deploy* e execução automatizada na nuvem, servindo como ferramenta centralizada de suporte à busca de oportunidades.

* **Desenvolvido por:** INOVHIA Desenvolvimento Tecnológico.
* **Plataforma de Execução:** Streamlit Community Cloud.

---

### ⚙️ Configuração para Deploy (Streamlit Cloud)
* **Main file path:** `elpis_app_v23_1.py`
* **Chave de IA (Gemini):** Opcional, configurada de forma segura nas definições de segredos (*Secrets*) da plataforma de hospedagem ou diretamente na interface.
